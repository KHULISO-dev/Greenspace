# Greenspace - Professional Botanical Research Tool

## Overview
Greenspace is a professional-grade field research application designed for botanical surveys, ecological monitoring, and plant data collection. Built with modern web technologies, it works seamlessly on both iOS and Android devices.

## Features
- 📍 GPS location tracking with interactive maps
- 📸 Photo capture and storage
- 📊 Comprehensive plant data recording
- 💾 Offline storage (localStorage)
- 📎 CSV and GeoJSON export
- 📱 Mobile-optimized interface
- 🔒 Secure local data storage

## Technology Stack
- HTML5 / CSS3 / JavaScript
- Leaflet.js for mapping
- LocalStorage for offline data
- Progressive Web App ready

## Installation
1. Place your logo as `assets/logo.png`
2. Place your small logo as `assets/logo-small.png`
3. Add feature images as `assets/1.png` through `assets/5.png`
4. Open `index.html` in any modern browser

## Usage
1. Enter plant name (required)
2. Get GPS location or enter coordinates manually
3. Add field notes and environmental data
4. Take or upload a photo
5. Save observation
6. Export data as CSV or GeoJSON
